# Кейс БСПБ: карьерный сайт банка «Санкт-Петербург»

Готовый кейс для портфолио: сокращённый текст + статическая HTML-вёрстка в стилистике БСПБ,
структура — по мотивам кейсов inostudio.com.

## Как открыть

```powershell
start index.html
```

Страница автономная: свой CSS, JS, шрифты и картинки. Внешних CDN и библиотек нет — можно открывать
локально, ставить на любой хостинг или вставлять в CMS как статическую страницу.

## Состав проекта

| Файл / папка | Что это |
| --- | --- |
| `index.html` | Готовая страница кейса |
| `case-text.md` | Сокращённый текст кейса (для согласования) + список правок |
| `assets/css/style.css` | Стили: фирменные токены БСПБ, типографика, адаптив, анимации |

| `assets/app.js` | Прогресс чтения, появление блоков, подсветка раздела, лайтбокс |
| `assets/img/*.jpg` | 6 скриншотов сайта и лендингов, 0,87 МБ |

## Структура страницы

Пронумерованные разделы с чередующимися фонами (белый / серый / тёмный) — так блоки читаются отдельно
и не сливаются:

| № | Раздел | Что внутри |
| --- | --- | --- |
| — | Hero | хлебные крошки, клиент, H1, лид, метаданные (4 пункта), скриншот главной |
| — | Цифры | 30 лет, 5 млн+ клиентов, 2 лендинга, 5 целей запроса |
| 01 | О клиенте | 2 колонки текста |
| 02 | Предпосылки | 2 колонки текста + два скриншота лендингов стажировок |
| 03 | Задача | 5 пронумерованных целей |
| 04 | Решение | три шага (01 номер слева, текст, скриншот справа) + тёмный акцентный блок «Защищённый контур» с тегами |
| 05 | Результат | тёмная секция, две карточки (кандидат / бизнес), CTA на job.bspb.ru |
| 06 | Технологии | интеграции и инфраструктура тегами |
| — | Футер | подпись «Иностудио» и ссылка на сайт |

Разделы разделяют: верхняя линия-хайрлайн, смена фона, крупные отступы (120 px), номер раздела
в красном надзаголовке и увеличенные заголовки — чтобы заголовки, подзаголовки и текст не «слипались».

## Стилистика

Токены сняты с CSS сайта `job.bspb.ru`:

```
--red          #F10D30   акцент, кнопки, номера
--black        #152126   тёмные секции, текст
--blue         #10385C   цифры, акцентный блок, тёмно-синий
--blue-light   #4C7397
--dusty        #CEDDED
--gray-100     #F5F8FA   фон чередующихся секций и карточек
--gray-200     #E3E9EC   линии-разделители
--gray-300     #B6C0C5
--gray-500     #707E85   вторичный текст
радиусы: кнопки 40px, карточки 24px, крупные блоки 32px
```

**Шрифты.** В самом БСПБ заголовки набраны Actay, текст — Gilroy; оба файла коммерческие, поэтому в проект
вложены свободные аналоги с той же геометрией: **Montserrat** (заголовки) и **Manrope** (текст), лицензия SIL OFL.
Файлы лежат в `assets/fonts/`, подключаются через `assets/css/fonts.css`. Если у вас есть лицензия на Actay/Gilroy —
положите их в ту же папку и поправьте `@font-face` в `fonts.css`, дальше менять ничего не нужно: в `style.css`
стек уже написан как `"Montserrat", "Actay Wide", "Actay", "Gilroy"` и `"Manrope", "Gilroy"`.

Чтобы заменить кадр — положите новый файл в `assets/img` с тем же именем (или поменяйте `src` в `index.html`).
Пропорции подписей держатся на атрибутах `width`/`height` у `<img>`, поэтому вёрстка не «прыгает».

## Публикация на GitHub Pages

Репозиторий уже инициализирован и закоммичен локально (ветка `main`, `.nojekyll` на месте) — остался только пуш.

```powershell
cd C:\Users\Roman\.cline\data\workspaces\chat\bspb-career-site-case

# 1) создать репозиторий (замените LOGIN и TOKEN)
curl.exe -X POST https://api.github.com/user/repos `
  -H "Authorization: Bearer TOKEN" -H "User-Agent: cline" `
  -d '{\"name\":\"bspb-career-site\",\"private\":false,\"description\":\"Кейс: карьерный сайт банка Санкт-Петербург\"}'

# 2) запушить
git remote add origin https://LOGIN:TOKEN@github.com/LOGIN/bspb-career-site.git
git push -u origin main
git remote set-url origin https://github.com/LOGIN/bspb-career-site.git   # убрать токен из конфига

# 3) включить GitHub Pages (ветка main, корень)
curl.exe -X POST https://api.github.com/repos/LOGIN/bspb-career-site/pages `
  -H "Authorization: Bearer TOKEN" -H "User-Agent: cline" `
  -d '{\"source\":{\"branch\":\"main\",\"path\":\"/\"}}'
```

Сайт будет доступен по адресу `https://LOGIN.github.io/bspb-career-site/` (страница собирается 1–2 минуты).
Требования к токену: classic PAT со scope `repo` (или fine-grained с правами `Contents: write` и `Pages: write`).
Токен из сообщения в чате GitHub уже отклонил (401) — нужен новый; после публикации токен лучше удалить.
