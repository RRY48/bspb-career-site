# Кейс БСПБ: карьерный сайт банка «Санкт-Петербург»

**Живая версия: <https://rry48.github.io/bspb-career-site/>** · репозиторий: `RRY48/bspb-career-site` (ветка `main`)

Кейс для портфолио, свёрстанный **по брендбуку Иностудио (2022)**: корпоративный шрифт, фирменная палитра,
логотип с точкой, круговой знак и паттерн из крупных геометрических пятен.

## Как открыть

```powershell
start index.html
```

Проект автономный: свой CSS, JS, шрифты и картинки. Внешних CDN и библиотек нет.

## Соответствие брендбуку

**Цвета** — ровно из раздела «Корпоративные цвета»:

```
--red        #E4003A   CMYK 0 100 70 0 · Pantone 199 C   акцент, кнопки, номера, ссылки-hover
--graphite   #3C3C3B   CMYK 0 0 0 90  · Pantone Black 7 C  тёмные секции, текст
--blue       #169FDB   CMYK 75 20 0 0    дополнительный (акценты, раздел 02)
--yellow     #FBBB21   CMYK 0 30 90 0    дополнительный (раздел 04)
--pink       #F39DB1   CMYK 0 50 15 0    дополнительный (раздел 05)
--green      #00A984   CMYK 80 0 60 0    дополнительный (раздел 03, верный ответ в игре)
--violet     #9373B1   CMYK 50 60 0 0    дополнительный (раздел 06)
--silver     #DADADA   CMYK 0 0 0 20     дополнительный (нейтраль, «выключенные» номера)
```

Белый фон и большие отступы — принцип брендбука «минимализм, воздух и белый цвет»; доп. цвета используются
только как акценты (номера разделов, теги, элементы игры), как и разрешает документ.

**Шрифт** — корпоративный **Montserrat** (Bold, Semibold, Medium, Regular, Light). Лежит локально в
`assets/fonts`, подключён без внешних CDN. Коммерческие Actay/Gilroy из фирстиля БСПБ не используются.

**Логотип** — **настоящий, извлечённый из брендбука** (`assets/img/logo-inostudio.png`): фирменная плашка
в красном #E4003A с белой надписью «.иностудио» (стр. 9 брендбука, «основной вариант»; брендбук прямо
запрещает версии с искажением прямоугольника и без точки). Используется в шапке, футере, прелоадере
и в DOCX. Логотип в векторе из PDF весит 180 КБ, поэтому сохранён растром 4x — 8 КБ, на экране 38 px
(эквивалент 6x, с запасом для retina).

**Фавикон** — `assets/img/favicon.png`: фирменная красная плашка со скруглением и белой точкой (точка —
обязательный элемент логотипа по брендбуку).

**Паттерн** — крупные геометрические пятна в корпоративных цветах: плавающие круги в hero (`hero__shapes`),
концентрические окружности в блоке «Защищённый контур» (`highlight__rings`), крупный «водяной знак»
`.иностудио` в футере.

**Фотоконтент** — скриншоты светлые, холодная гамма, с акцентом корпоративного цвета (плашка на hero,
бегущая строка), как рекомендует раздел «Соцмедиа · фотоконтент».

## Динамика и интерактив

| Элемент | Что делает |
| --- | --- |
| Прелоадер | тёмный экран с вращающимся кольцом и логотипом, плавно уходит после загрузки |
| Hero | заголовок собирается по словам (`--i`), пульсирующая точка логотипа, плавающие круги следуют за курсором |
| Бегущая строка | две бесконечные ленты (под hero и в футере), на hover останавливаются |
| Цифры | анимированные счётчики при входе в экран + выезжающая красная черта |
| Секции 01–06 | чередование фонов, круговые номера в цветах брендбука, появление заголовков и текста со сдвигом |
| Шаги решения | номер меняет цвет на фирменный красный при появлении, кадры открываются «шторкой» |
| Мини-игра | «Город или банк?» — 3 вопроса, прогресс-точки, пояснения, счёт и кнопка «Сыграть ещё раз» |
| Скролл | прогресс-бар чтения, сжатие шапки, кнопка «наверх», подсветка активного раздела в меню |
| Кадры | подъём при наведении, зум, лайтбокс по клику (Esc — закрыть) |

Всё на CSS + ванильном JS, `IntersectionObserver` + `requestAnimationFrame`. При
`prefers-reduced-motion: reduce` анимации отключаются, счётчики показывают финальные значения.

Сняты с живого сайта в headless Chrome (1440 px, сжаты в JPEG q88, 1280 px по ширине):

- `career-site-hero.jpg` — главная страница (hero);

- `career-site-candidate-path.jpg` — блок «Путь кандидата»;
- `career-site-quiz.jpg` — викторина «Город или банк?»;
- `career-site-vacancy-detail.jpg` — вакансия с формой отклика.

Заменить кадр — положить файл с тем же именем в `assets/img` (или поменять `src` в `index.html`).
Пропорции держатся на атрибутах `width`/`height` у `<img>`, поэтому вёрстка не «прыгает».

## DOCX с сокращённым текстом

`case-text.docx` (и копия на рабочем столе: `Desktop\ИИ\корпсайт\Кейс БСПБ - сокращённый текст.docx`)
собран из `case-text.md` скриптом, поэтому текст в Word и на сайте идентичен. Оформление — по брендбуку
для деловой документации:

- шрифт **Arial** (брендбук: «для оформления деловой документации используется шрифт Arial»);
- официальный **логотип из брендбука** в шапке документа и фирменная красная линия под заголовком;
- заголовки разделов — фирменный красный #E4003A, метаданные — компактной таблицей, колонтитул `.иностудио`;
- структура: логотип → заголовок → метаданные → 01–06 → «Что сокращено для сверки с клиентом».

Пересобрать после правок текста:

```powershell
python "$env:TEMP\bspb\make_docx.py"
```
